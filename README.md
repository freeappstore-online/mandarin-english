# Mandarin English

Translate and practise phrases in any language. Auto-translation, pinyin, and tap-to-speak. Perfect for language exchange prep.

**Live:** https://mandarin-english.freeappstore.online

A free app on [FreeAppStore](https://freeappstore.online). App id: `mandarin-english`.

## Develop

```bash
pnpm install
pnpm dev
pnpm build
pnpm run typecheck
pnpm test
```

Before publishing, run `fas check` (`npm i -g @freeappstore/cli`). Pushing to `main` deploys the app.
